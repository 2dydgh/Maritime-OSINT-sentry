# Maritime decision evidence ontology

`maritime.ttl` is the OWL vocabulary; `shapes.ttl` contains the SHACL data constraints. Instance graphs are generated by `evidence.py` from existing SQLite records for one proposal at a time. Queries in `queries/` are fixed, parameter-bound SPARQL queries. No remote import, arbitrary query, or new write path is introduced by the knowledge API.

See [the feature documentation](../../docs/features/ontology-evidence.md) for mapping semantics, UI, API and validation instructions.
