# 충돌 시나리오 비교

제안 카드의 **사건 검토 → 속력·침로 조건 비교**로 들어갑니다. CPA·AI 분석 카드의 시나리오 비교에서도 열 수 있습니다. 선택 선박 두 척과 주변 AIS를 저장한 뒤 변경할 선박, 속력, 침로, 예측 시간(5~30분)을 입력합니다. **조건 비교하기**는 기준 유지와 변경안을 동일한 시작 조건에서 계산하고 결과를 SQLite에 저장합니다.

속력·침로 칸은 그 선박의 **현재 값으로 채워집니다**. 이 칸은 현재 상태를 보는 곳이 아니라 "이렇게 피했다면" 가정을 넣는 곳이므로, 값을 바꾸지 않으면 기준과 변경안이 같아져 결과가 모두 `변화 없음`이 됩니다. 그래서 바뀐 값이 없으면 **조건 비교하기가 잠기고** 안내 문구가 나타납니다. **우현 20° · 좌현 20° · 감속 50%** 프리셋은 현재 값을 기준으로 상대 변경한 값을 입력칸에 채워 넣습니다(계산은 여전히 조건 비교하기로 실행). **현재 값으로**는 입력을 되돌립니다.

계산 후 **비교 결과 · 두 가지를 함께 확인하세요** 안내가 나타나고 결과로 이동합니다. 두 선박 최소 거리와 주변 선박 근접이 각각 어떻게 바뀌는지 확인하세요. 제안에 연결된 비교라면 필요한 검토 이유를 남긴 뒤 **사건 검토로 돌아가기**로 복귀합니다. 후속 관측·예측 비교는 별도의 접힌 선택 항목이며 비교나 집중 추적 승인을 위한 필수 단계가 아닙니다.

지도에서 파랑 점선은 변경 대상의 기준 항적, 주황 실선은 변경 항적, 흰색은 상대 선박, 회색은 주변 선박입니다. **3D 재생**은 기존 Three.js/ShipBuilders를 활용해 같은 저장 항적을 재생합니다. 시간 슬라이더와 재생 위치는 두 화면에서 공유합니다. 3D에는 기존 Three.js Water·Sky 기반 수면, 잔물결, 하늘 반사가 표시됩니다. **전체 항적**은 비교 경로를 함께 보여주며 기본 30배속, **변경 선박 가까이**는 기본 3배속으로 선박을 부드럽게 따라갑니다. 재생 속도에서 1·3·10·30배속을 선택할 수 있습니다. **시점 고정**은 현재 카메라 위치를 유지해 선박이 지나가는 모습을 보여줍니다. 드래그로 회전하고 휠로 확대할 수 있습니다. 카메라는 선회 각도에 맞춰 자동 회전하지 않으며 시간 슬라이더 이동 시에는 선택 시점으로 바로 이동합니다. 일시정지하면 카메라 추적과 수면 애니메이션도 멈춥니다. 잔물결은 재생 배속과 독립적인 시각 효과이며 시간 슬라이더로 과거 파도 상태를 재현하지 않습니다. 탭 중단 등으로 프레임 간격이 0.25초를 넘으면 그 공백은 재생 시간에 더하지 않습니다. 바다는 시각적 배경이며 실제 위치의 해안·수심을 재현하거나 파도·해류의 영향을 계산하지 않습니다. 선박 모델은 가독성을 위해 확대되므로 선체 겹침을 충돌 판정으로 해석하지 않습니다.

선체의 좌우 기울기(횡요), 앞뒤 기울기(종요), 상하 움직임도 표시합니다. 기존 횡요 화면의 `Gerstner` 파도 모듈을 고정된 약한 시각 프리셋으로 사용하며 실제 기상·선체 복원성·횡요 예측 결과를 적용한 것은 아닙니다. 표시 각도는 좌우 최대 5도, 앞뒤 최대 2.5도로 제한합니다. 항적과 침로를 담당하는 바깥 그룹 안에서 선체만 움직이므로 카메라와 수평선은 함께 흔들리지 않습니다. **선체 동요** 버튼으로 효과를 끌 수 있고, 일시정지하면 동요도 멈춥니다. 이 효과는 수면 형상과의 정밀한 접촉·부력 계산을 제공하지 않으며 저장된 비교 수치에 영향을 주지 않습니다.

결과는 **차이를 먼저** 보여줍니다. 두 선박 최소 거리와 주변 0.5해리 미만 쌍 수를 각각 `기준 → 변경안` 으로 나란히 놓고 변화량과 방향(벌어짐/가까워짐, 늘어남/줄어듦)을 함께 표시합니다. 주의가 필요한 방향 — 거리가 줄었거나 주변 근접 쌍이 늘어난 경우 — 에만 색이 붙습니다. 벌어진 쪽에는 색을 쓰지 않습니다. 이 계산은 안전 판정이 아니므로 "안전해졌다"로 읽히면 안 되기 때문입니다.

그 아래 기준 유지·변경안 각각의 원시값(최소 거리, 발생 시점, 주변 0.5해리 미만 쌍 수, 산출 방식)을 표시합니다. 구간 밖 CPA 또는 상대 속도가 없는 경우는 산출 항목에 따로 적습니다. 가까운 순서 최대 10개 주변 결과는 하단 접힘 영역에 있습니다. 0.5해리는 비교 표시 기준이며 안전 판정 기준이 아닙니다.

충돌 분석 패널 헤더의 **저장한 비교** 또는 비교창 툴바의 **저장한 비교**에서 최근 20개 결과를 다시 열 수 있습니다. 재생에는 현재 AIS를 다시 사용하지 않습니다. 이 기능은 가정 비교이며 기존 집중 추적 승인과 별개입니다. 변경안을 승인하거나 실제 운항 명령을 보내는 기능은 없습니다.

## 계산 범위

- 로컬 수신 후 60초 이내이고 위치·SOG·COG가 유효한 선박 두 척만 새 비교를 시작할 수 있습니다.
- 수신 시각부터 캡처 시각까지 등속 투영해 시작 시점을 맞춥니다. 로컬 수신 시각은 실제 센서 관측 시각이 아닙니다.
- 초기 선박 간 20해리 이내, 위도 ±80도 범위의 로컬 평면 근사입니다.
- 초기 두 척 주변 10해리 이내의 유효한 AIS 중 가까운 최대 50척을 포함합니다. 미수신·오래된 데이터·범위 밖 진입 선박 때문에 주변 평가는 항상 부분적입니다.
- 변경은 한 척의 속력(0~50kt)과 침로(0~360도 미만)에 적용합니다. 선회·속력 변경 시간을 지정할 수 있으며, 0초이면 즉시 적용합니다. 선박별 실제 성능, 해안·수심·항법규칙·기상은 평가하지 않습니다.
- 정속 모델의 최소 거리는 해석적으로 계산하고, 선회 모델은 1초 적분과 구간 선형 보간으로 계산합니다. 지도·3D는 동일한 10초 간격 저장 표본 사이를 보간해 재생합니다.

## API와 저장

- `POST /api/v1/collision/scenarios/snapshots`: `mmsi_a`, `mmsi_b`
- `POST /api/v1/collision/scenarios/runs`: `snapshot_id`, `target`, `speed`, `course`, `minutes`
- `GET /api/v1/collision/scenarios/runs`: 최근 20개 기록
- `GET /api/v1/collision/scenarios/runs/{id}`: 입력 조건·주변 포함 범위·모델 버전·결과·항적

`SCENARIO_DB` 기본값은 `var/data-platform/collision-scenarios.sqlite3`입니다. Docker의 기존 데이터 플랫폼 볼륨 안에 저장됩니다. 현재 자동 보존기간/삭제 정책은 없으므로 장기 운영 시 용량 관리가 필요합니다. [운영·백업 안내](../data-platform/operations.md)를 참고하세요.

검증: `tests/test_collision_scenarios.py`는 교차/정면 근접, 구간 밖·평행 CPA, 주변 위험 악화, 동일 시작점·변경 대상 격리, 수신 신선도, 입력 검증, 저장 후 재생 API를 확인합니다.

## 선회·속력 변경 시간 가정

화면에서 선회 시간과 속력 변경 시간을 각각 0~300초로 입력합니다. 새 비교의 화면 기본값은 60초·120초이며 선박별 성능에서 추정한 값이 아닙니다. 0초는 즉시 변경입니다. API에서 생략하면 기존 동작과 호환되도록 0초를 사용합니다.

시간을 지정하면 `ramped-motion-local-plane-v1` 모델을 사용합니다. 속력은 선형 가감속하고 침로는 짧은 방향으로 선형 회전합니다(정확히 180도는 시계 방향). 1초 간격 중점 적분으로 위치를 계산하고 각 구간에서 선형 상대 운동의 최소 거리를 구합니다. 화면은 10초 표본을 보간해 재생하며 선박 방향도 바뀝니다. 기준 유지 항적은 기존 정속 모델을 유지합니다.

변경안의 지표는 지정 기간 내 최소 거리·시점이며 정속 운동의 무제한 DCPA/TCPA로 표기하지 않습니다. 기존 즉시 변경 모델로 저장한 비교도 그대로 재생됩니다. 실제 선회 반경·조타 응답·기관 성능·해안·수심·항법규칙 제약은 아직 반영하지 않습니다.

API 추가 입력: `turn_seconds`, `speed_seconds`.
